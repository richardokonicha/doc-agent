# Quickstart

Find a file or directory by walking up parent directories

## Install

```bash
npm install find-up
```

## Example

```typescript
import { findUpStop } from 'find-up';

console.log(findUpStop);
```

## What This Does

Find a file or directory by walking up parent directories

The example imports the `findUpStop` export and demonstrates basic usage. Check the source code and tests for more advanced examples.
