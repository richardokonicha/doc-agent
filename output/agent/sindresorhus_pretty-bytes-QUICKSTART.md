# Quickstart

Convert bytes to a human readable string: 1337 → 1.34 kB

## Install

```bash
npm install pretty-bytes
```

## Example

```typescript
import { prettyBytes } from 'pretty-bytes';

const result = prettyBytes("number", {});
console.log(result);
```

## What This Does

Convert bytes to a human readable string: 1337 → 1.34 kB

The example imports the `prettyBytes` export and demonstrates basic usage. Check the source code and tests for more advanced examples.
