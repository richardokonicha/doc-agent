# Quickstart

Human-friendly and powerful HTTP request library for Node.js

## Install

```bash
npm install got
```

## Example

```typescript
import { asPromise } from 'got';

const result = asPromise("firstRequest?");
console.log(result);
```

## What This Does

Human-friendly and powerful HTTP request library for Node.js

The example imports the `asPromise` export and demonstrates basic usage. Check the source code and tests for more advanced examples.
