# Quickstart

Check if argv has a specific flag

## Install

```bash
npm install has-flag
```

## Example

```typescript
import { hasFlag } from 'has-flag';

const result = hasFlag("flag", "argv = process.argv");
console.log(result);
```

## What This Does

Check if argv has a specific flag

The example imports the `hasFlag` export and demonstrates basic usage. Check the source code and tests for more advanced examples.
