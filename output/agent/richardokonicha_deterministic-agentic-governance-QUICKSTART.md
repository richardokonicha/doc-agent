# Quickstart

Deterministic Agentic Governance Framework for Autonomous Software Engineering

## Install

```bash
npm install @deterministic-agentic/governance
```

## Example

```typescript
import { createGovernanceConfig } from '@deterministic-agentic/governance';

const instance = await createGovernanceConfig("./workspace", "my-project");
console.log(instance);
```

## What This Does

Deterministic Agentic Governance Framework for Autonomous Software Engineering

The example imports the `AgentAdapter` export and demonstrates basic usage. Check the source code and tests for more advanced examples.
