# Quickstart

A utility library for JavaScript and Typescript.

## Install

```bash
npm install remeda
```

## Example

```typescript
import { add } from 'remeda';

const result = add("value", "addend");
console.log(result);
```

## What This Does

A utility library for JavaScript and Typescript.

The example imports the `add` export and demonstrates basic usage. Check the source code and tests for more advanced examples.
