# Quickstart

Convert Windows backslash paths to slash paths

## Install

```bash
npm install slash
```

## Example

```typescript
import { slash } from 'slash';

const result = slash("./workspace");
console.log(result);
```

## What This Does

Convert Windows backslash paths to slash paths

The example imports the `slash` export and demonstrates basic usage. Check the source code and tests for more advanced examples.
